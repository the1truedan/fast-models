Import

  1. Cron deploy/observability/ai_data_stats_exporter.sh every 15 minutes on the NAS host.
  2. node_exporter --collector.textfile.directory on that output dir.
  3. Prometheus scrapes the node_exporter — see prometheus-scrape.example.yml.
  4. Grafana → Import → grafana-bees-dashboard.json (uid fast-models-bees-dedupe).

Do not treat content-hash “reclaimable GB” as bees savings. That series is optional and only appears if you pass AUDIT_JSON.
